Intelligent Systems in Informatics – Pathfinding Levels

This project was developed as part of the Intelligent Systems in Informatics course.

It is a pair assignment focused on implementing and comparing classical search algorithms for pathfinding in a grid-based environment.

The main objective was to allow an autonomous agent (car) to navigate from a starting position to an exit on a playing field with obstacles.

The following algorithms were implemented and used for pathfinding:

Depth-First Search (DFS)
Greedy Best-First Search
A* Search Algorithm

The project demonstrates how different search strategies affect the efficiency and quality of the найден path, especially in terms of performance and optimality.

The results were evaluated by comparing how each algorithm guides the agent through the grid to successfully reach the goal (exit).
